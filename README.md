# kuva

1枚の写真を入力に、**多状態の1次元セルオートマトン（CA）で崩れ続ける映像**をブラウザ上でリアルタイムに生成するツールです。VJ や展示で、このページをそのまま流したり映したりすることを想定しています。

**公開ページ：https://ogrew.github.io/kuva/** （Chrome デスクトップ推奨）

写真はブラウザの中だけで処理され、どこにも送信・保存されません。

写真をマス目に分割し、各マスを「写真のタイル」として扱います。CA のルールに従ってタイルが複製・伝播し、場所ごとに異なるルールで同じマス目が繰り返されます。その模様が、止まらずに流れ、ときどき形を変えていきます。

## kivi から生まれたプロジェクト

kuva は、同じ作者が開発している静止画ツール **kivi** を元に作った姉妹プロジェクトです。kivi は、写真1枚を多状態の1次元 CA で「崩した」静止画を書き出す画像編集ツールです（公開は未定）。表現の核は kivi と同じです。

- 何かのルールに従って、同じマス目が繰り返されている
- そのルールは画像内で1つとは限らず、場所によって異なる
- pure glitch 的な混沌の中に、よく見ると元の写真が分かる程度の破綻

kivi は CA の時間の進みを画像の縦（または横）方向に並べ、「時空図」を1枚の静止画にします。kuva はその時空図を**映像の時間に沿って流し続けます**。

| | kivi | kuva |
|---|---|---|
| 出力 | 静止画1枚 | リアルタイムの映像 |
| CA の時間 | 画像の空間（縦・横）に並べる | 映像の時間。時空図が領域の中を流れ続ける |
| kivi から流用 | ― | セルの平均色、k-means（輝度順）、ルール表、領域の再帰分割、写真タイル（`src`）の伝播 |
| 作り直し | ― | 描画（WebGL2）、時間の進め方、GUI |

## 動かし方

Node 22 以上が必要です。

```sh
npm install
npm run dev
# → http://localhost:5173/
```

ブラウザ（**Chrome デスクトップ**）で開くと、サンプル画像（`samples/` にあるもの）からランダムに1枚を選んで再生が始まります。写真をドラッグ&ドロップすると、その写真に入れ替わります。

サンプル画像は `samples/` に置くだけで候補に入ります（PNG・JPEG・WebP）。今入っている6枚は、AI で生成した画像です。

開発用に `?img=画像のURL` でも読み込めます（例：`http://localhost:5173/?img=/samples/sample01.png`）。

| ライブラリ | 用途 |
|---|---|
| Vite | 開発サーバ・ビルド |
| Tweakpane 4.0.5 | GUI（kivi と同じ） |
| （WebGL2） | 描画。ライブラリは使っていない |

## 操作

操作はキーボードで行います。一覧は GUI の一番下にも出ています。

| キー | 名前 | 操作 |
|---|---|---|
| Space | PLAY / PAUSE | 再生／一時停止（タブが非アクティブになると自動で一時停止し、戻っても止まったまま） |
| N | NEW SEED | 新しい seed で作り直し |
| R | RESET | 最初（0世代）から |
| F | FULLSCREEN | フルスクリーン |
| H | HIDE GUI | GUI の表示／非表示（カーソルも隠れる） |

## パラメータ

GUI は右上です。左下の「状態」パネルに、メッセージ、再生中かどうか、世代、実測の世代/秒（グラフつき）、グリッド、領域の数、seed、写真の情報が出ます。H で両方とも隠れます。**作り直し**のパラメータは変えると0世代からやり直し、**即時**のパラメータは再生を止めずに次の世代から反映されます。

サイトを開いたときは、seed・cellSize（写真の短辺の 1%〜6%）・K（4〜10）・動き方がランダムに決まります。開くたびに違う映像になります。

### 基本

| パラメータ | 反映 | 内容 |
|---|---|---|
| seed | 作り直し | 乱数シード。同じ写真・同じパラメータ・同じ seed なら、同じ世代で同じ映像になる |
| cellSize | 作り直し | 1マスの幅（元写真の px）。範囲は写真の短辺の 0.5%〜12.5%（最小 4px）で、写真を入れ替えると範囲も変わる（範囲の外なら寄せる） |
| 高さ比 | 作り直し | 1マスの高さ = 幅 × [1/5, 1/4, 1/3, 1/2, 1, 2, 3, 4, 5]（kivi と同じ）。領域の細かさは実際の長さで決まるので、マスの形を変えても構図の細かさは保たれる |
| K | 作り直し | 状態数。各マスを平均色で K 個に分類し（k-means、輝度順に番号付け）、CA はこの番号だけを見て動く |
| 動き方 | 作り直し | 流れる：時空図が領域の中を一方向に流れ続ける（基本）／その場で変化：各行がその場で1D CA として変わる（比較用。点滅に見える） |
| 進行方向 | 即時 | ALL：領域ごとに違う向き（E では、ときどき変わる）／下／上／右／左：全領域をその向きに流す。ALL に戻すと各領域の向きに戻る |
| chaos | 即時 | ルール表に混ぜる完全ランダムの割合 |
| 世代/秒 | 即時 | CA が1秒に進む世代数。表示の fps とは切り離されている |
| 縦横比 | 即時 | 全体を収める（余白）／埋める（切り取り） |
| 塗りつぶし割合 | 即時 | CA で運ばれてきたマス（元の位置にない写真タイル）のうち、写真の代わりに一色で塗る割合。0 なら塗らない。元の位置にあるタイルは塗らない |
| └ 塗り方 | 即時 | マスごと：写真タイルごとに塗るかを決める／似た色ごと：K色に分けたとき同じ色になるタイルをまとめて塗る（大きな色面になりやすい）。割合が 0 のときは非表示 |
| └ 塗りの色 | 即時 | 代表色：K色のうち、そのタイルが属する色／平均色：そのタイル自身の平均の色。割合が 0 のときは非表示 |

### 変化

時間とともに映像を変え、似た模様が画面全体で繰り返されて見えるのを防ぐための仕組みです。

| パラメータ | 反映 | 内容 |
|---|---|---|
| ルールの味付け | 作り直し | なし：ルールをぱっと切り替える／少しずつ変形：ルール表の項目を数百世代かけて次のルールの値に置き換える／領域ごとのルール：ルールを領域ごとに作り、性格（保持・明暗・横シフト・合計型）と写真へ戻る割合も抽選する／両方（既定） |
| └ 保持（最大）・変形（最短・最長） | 即時 | 「少しずつ変形」の周期（世代）。保持 → 変形 → 保持 … を繰り返す（味付けが「少しずつ変形」か「両方」のときのみ表示） |
| 写真を流し込む | 即時 | 周期ごとに、領域の上流から元写真が滑り込み、元の位置に並んでから、また崩れていく。領域ごとに時期はずれる（流れるのときのみ有効） |
| └ 周期 | 即時 | 流し込みの周期（世代、20〜600） |
| 領域ごとのテンポ | 即時 | 領域ごとに進む速さが違う。100〜500世代ごとに速さが変わり、ときどき流れる向きも変わる |
| └ 最速・最遅 | 即時 | 速さの範囲。×2（1世代に2回）、×1、×1/2、×1/3、×1/4、×1/5 の6段階 |

### 実験

試しているものです。採用するかは未定です。

| パラメータ | 反映 | 内容 |
|---|---|---|
| 模様の領域の割合 | 即時 | この割合の領域（行の長さが24マス以上）に、基本セルオートマトンの模様を重ねる。模様は領域ごとに決めた1枚の写真タイルで描く（領域の写真が明るければ暗いタイル、暗ければ明るいタイル）。領域の上流の端に置いた種から模様が生まれて流れていく。0 なら模様なし |
| └ ルール30・90・110・150 | 即時 | 模様に使うルール。各領域は ON のルールの中から1つを使う。全部 OFF なら模様なし |

## 決定性

映像の中身は **seed・パラメータ・世代番号** だけで決まります。壁時計の時間やフレーム落ちには依存しません（処理が追いつかないときは、ゆっくりになるだけで、中身は変わりません）。

再生中に即時のパラメータを変えた場合も、「何世代目に何をいくつに変えたか」が同じなら同じ映像になります。この操作の記録・再生（と PNG 書き出し）はまだ実装していません。

## ファイル構成

```
index.html              エントリ（キャンバスと情報表示）
src/
  main.js               画像の読み込み、GUI、キー操作、再生ループ
  image.js              グリッド配置、パディング、縮小（kivi から流用）
  engine/               エンジン本体。DOM に依存しない純粋な JS（Node でも動く）
    sim.js              Simulation：世代番号・状態・step()、再生中に変えられるパラメータ
    analyze.js          平均色 → k-means → 分類 → 代表タイル（kivi から流用）
    rules.js            ルール表（性格、chaos の即時反映）
    regions.js          領域の再帰分割（kivi から流用）
    flat.js             塗りつぶすタイルの選び方（kivi の pickFlat を kuva 向けに）
samples/                サンプル画像（開いたときにランダムに1枚を表示）
    motions.js          領域の動き方（流れる／その場で変化／元写真のまま）、ルールの変形、写真の流し込み
    rng.js              乱数とハッシュ
  render/renderer.js    WebGL2 描画
test/                   Node のテスト（npm test）
```
