# kuva

1枚の写真を入力に、**多状態の1次元セルオートマトン（CA）で崩れ続ける映像**をブラウザ上でリアルタイムに生成するツールです。VJ や展示で、このページをそのまま流したり映したりすることを想定しています。

**公開ページ：https://ogrew.github.io/kuva/** （Chrome デスクトップ推奨）

写真はブラウザの中だけで処理され、どこにも送信・保存されません。

写真をマス目に分割し、各マスを「写真のタイル」として扱います。CA のルールに従ってタイルが複製・伝播し、場所ごとに異なるルールで同じマス目が繰り返されます。その模様が、止まらずに流れ、ときどき形を変えていきます。

## kivi から生まれたプロジェクト

kuva は、同じ作者が開発している静止画ツール **kivi** を元に作った姉妹プロジェクトです。kivi は、写真1枚を多状態の1次元 CA で「崩した」静止画を書き出す画像編集ツールです（公開は未定）。表現の核は kivi と同じです。

- 何かのルールに従って、同じマス目が繰り返されている
- そのルールは画像内で1つとは限らず、場所によって異なる
- pure glitch 的な混沌の中に、よく見ると元の写真が分かる程度の破綻

kivi は CA の時間の進みを画像の縦（または横）方向に並べ、「時空図」を1枚の静止画にします。kuva はその時空図を**映像の時間に沿って流し続けます**。

| | kivi | kuva |
|---|---|---|
| 出力 | 静止画1枚 | リアルタイムの映像 |
| CA の時間 | 画像の空間（縦・横）に並べる | 映像の時間。時空図が領域の中を流れ続ける |
| kivi から流用 | ― | セルの平均色、k-means（輝度順）、ルール表、領域の再帰分割、写真タイル（`src`）の伝播 |
| 作り直し | ― | 描画（WebGL2）、時間の進め方、GUI |

## 動かし方

Node 22 以上が必要です。

```sh
npm install
npm run dev
# → http://localhost:5173/
```

ブラウザ（**Chrome デスクトップ**）で開くと、サンプル画像（`samples/` にあるもの）からランダムに1枚を選んで再生が始まります。写真をドラッグ&ドロップすると、その写真に入れ替わります。

サンプル画像は `samples/` に置くだけで候補に入ります（PNG・JPEG・WebP）。今入っている6枚は、AI で生成した画像です。

開発用に `?img=画像のURL` でも読み込めます（例：`http://localhost:5173/?img=/samples/sample01.png`）。

| ライブラリ | 用途 |
|---|---|
| Vite | 開発サーバ・ビルド |
| Tweakpane 4.0.5 | GUI（kivi と同じ） |
| （WebGL2） | 描画。ライブラリは使っていない |

## 操作

操作はキーボードで行います。一覧は GUI の一番下にも出ています。

| キー | 名前 | 操作 |
|---|---|---|
| Space | PLAY / PAUSE | 再生／一時停止（タブが非アクティブになると自動で一時停止し、戻っても止まったまま） |
| N | NEW SEED | 新しい seed で作り直し |
| R | RESET | 最初（0世代）から |
| F | FULLSCREEN | フルスクリーン |
| H | HIDE GUI | GUI の表示／非表示（カーソルも隠れる） |
| S | SAVE PNG | 今の世代を PNG で保存。元写真の範囲だけを、写真と同じ解像度（長辺は最大 4096px）で書き出す（画面の余白・切り取りには関係しない）。ファイル名は `kuva_s<seed>_g<世代>.png`。再生中でも押せる |

## パラメータ

GUI は右上です。左下の Status パネルに、メッセージ、再生中かどうか、世代、実測の世代/秒（グラフつき）、グリッド、領域の数、seed、写真の情報が出ます。H で両方とも隠れます。**作り直し**のパラメータは変えると0世代からやり直し、**即時**のパラメータは再生を止めずに次の世代から反映されます。

サイトを開いたときは、Seed・Cell size（写真の短辺の 1%〜6%）・Colors（4〜10）がランダムに決まります（Motion は常に Flow）。開くたびに違う映像になります。

### Grid

| パラメータ | 反映 | 内容 |
|---|---|---|
| Seed | 作り直し | 乱数シード。同じ写真・同じパラメータ・同じ seed なら、同じ世代で同じ映像になる |
| Cell size | 作り直し | 1マスの幅（元写真の px）。範囲は写真の短辺の 0.5%〜6.25%（最小 4px）で、写真を入れ替えると範囲も変わる（範囲の外なら寄せる） |
| Aspect | 作り直し | 1マスの高さ = 幅 × [1/5, 1/4, 1/3, 1/2, 1, 2, 3, 4, 5]（kivi と同じ）。領域の細かさは実際の長さで決まるので、マスの形を変えても構図の細かさは保たれる |
| Colors | 作り直し | 状態数 K。各マスを平均色で K 個に分類し（k-means、輝度順に番号付け）、CA はこの番号だけを見て動く |
| Big cells | 即時 | 大きなマスにする領域の割合（0〜1、初期値 0.3）。選ばれた領域は 2×2 か 4×4 マス（半々）を1マスとして計算し、写真も大きなタイルとして運ぶ。大きなマスは 2・4 世代に1回進むので、画面上の流れる速さは他の領域と同じ。大きなマスが短い辺に4つ並ばない領域は小さい倍率になる。塗りつぶし・2色塗り・数字も大きなマス1つ単位。模様は重ならない。0 なら全領域が Cell size のまま |
### Motion

| パラメータ | 反映 | 内容 |
|---|---|---|
| Motion | 作り直し | Flow：時空図が領域の中を一方向に流れ続ける（基本）／In place：各行がその場で1D CA として変わる（比較用。点滅に見える） |
| Direction | 即時 | All：領域ごとに違う向き（Region tempo では、ときどき変わる）／Down／Up／Right／Left：全領域をその向きに流す。All に戻すと各領域の向きに戻る |
| Chaos | 即時 | ルール表に混ぜる完全ランダムの割合 |
| Speed | 即時 | CA が1秒に進む世代数（0.5〜48、初期値15）。表示の fps とは切り離されている |

### Render

| パラメータ | 反映 | 内容 |
|---|---|---|
| Region borders | 即時 | 領域の境界を細い白線で表示するデバッグ用チェックボックス。初期値 OFF。再生・停止中どちらでも切り替え可能で、ON のときは PNG 保存にも含まれます。H で GUI を隠しても境界線は残ります |
| Digits | 即時 | マスに数字 0〜9 を重ねる（Aspect が ×1 のときだけ表示・動作）。数字は写真タイルごとに決まり、タイルと一緒に流れる（同じ柄なら同じ数字）。文字の大きさはマスに収まる最大。PNG 保存にも含まれる。初期値 OFF |
| └ By | 即時 | 数字の決め方。Brightness：タイルの平均色の明るさで10段階（写真ごとに、どの数字もほぼ同じ数ずつ出るよう区切る。暗い = 0）／State：K色の分類（CA が見ている状態）。K が 11 以上なら一の位 |
| └ Font | 即時 | Grotesk／Mono／7-segment／Dot 5×7／Silkscreen／Orbitron。7-segment と Dot 5×7 はフォントを使わずに図形として描く。初期値は Silkscreen |
| └ Color | 即時 | 数字の色（全マス共通） |
| └ Show | 即時 | 描く数字（0〜9 の切り替え）。初期値は 0 と 1 だけ |
| Fit | 即時 | Contain：全体を収める（余白）／Cover：埋める（切り取り） |
| Flat fill | 即時 | CA で運ばれてきたマス（元の位置にない写真タイル）のうち、写真の代わりに一色で塗る割合。0 なら塗らない。元の位置にあるタイルは塗らない |
| └ Group | 即時 | Per tile：写真タイルごとに塗るかを決める／Per color：K色に分けたとき同じ色になるタイルをまとめて塗る（大きな色面になりやすい）。割合が 0 のときは非表示 |
| └ Color | 即時 | Palette：K色のうち、そのタイルが属する色／Mean：そのタイル自身の平均の色。割合が 0 のときは非表示 |
| └ Split | 即時 | 2色塗りにする領域の割合。塗るタイルを2つに割り、それぞれの半分の色で塗る（色の決め方は Color に従う）。割り方（横・縦・斜め2方向）は領域ごとに、その領域の写真で2色の差がいちばん大きく出るものが選ばれる。上げると2色塗りの領域が増えるだけで、入れ替わらない。0 なら1色塗りのみ。Flat fill が 0 のときは非表示 |

### Evolve

時間とともに映像を変え、似た模様が画面全体で繰り返されて見えるのを防ぐための仕組みです。

| パラメータ | 反映 | 内容 |
|---|---|---|
| Rule mode | 作り直し | Switch：ルールをぱっと切り替える／Morph：ルール表の項目を数百世代かけて次のルールの値に置き換える／Per region：ルールを領域ごとに作り、性格（保持・明暗・横シフト・合計型）と写真へ戻る割合も抽選する／Morph + region：両方。初期値は Morph |
| └ Hold max・Morph min・Morph max | 即時 | Morph の周期（世代）。保持 → 変形 → 保持 … を繰り返す（Rule mode が Morph か Morph + region のときのみ表示） |
| Reinject | 即時 | 周期ごとに、領域の流れの上流側の辺から元写真が滑り込み、元の位置に並んでから、また崩れていく。領域ごとに時期はずれる。流れ込む向きは領域の流れる向きと同じで、領域ごとに上下左右いずれか（Direction で固定したときはその向き）（Flow のときのみ有効）。初期値は ON |
| └ Period | 即時 | 流し込みの周期（世代、20〜360、初期値120） |
| Region tempo | 即時 | 領域ごとに進む速さが違う。100〜500世代ごとに速さが変わり、ときどき流れる向きも変わる |
| └ Fastest・Slowest | 即時 | 速さの範囲。×2（1世代に2回）、×1、×1/2、×1/3、×1/4、×1/5 の6段階 |
| Stagger | 即時 | 領域が崩れ始める時期のばらつき（世代、0〜300）。各領域は 0〜この値の間のどこかの世代まで元写真のまま待ち、そこから崩れ始める。0 なら全領域が一斉に始まる。途中で変えても、すでに始まった領域は止まらない。初期値は 150 |

### Pattern

写真の上の一部に、基本セルオートマトン（1次元の2状態 CA）の模様を重ねます。「この部分はルールで描かれている」と分かる模様を、部分的に出すためのものです。

| パラメータ | 反映 | 内容 |
|---|---|---|
| Amount | 即時 | この割合の領域（行の長さが24マス以上）に、基本セルオートマトンの模様を重ねる。模様は領域ごとに決めた1枚の写真タイルで描く（領域の写真が明るければ暗いタイル、暗ければ明るいタイル）。領域の上流の端に置いた種から模様が生まれて流れていく。0 なら模様なし。初期値は 0.2 |
| └ Rule 30・90・110・150 | 即時 | 模様に使うルール。各領域は ON のルールの中から1つを使う。全部 OFF なら模様なし |

## 領域の変化

GUI の Evolve で、次の2機能を個別に ON/OFF できます。初期状態はどちらも OFF で、従来と同じ映像になります。サブパラメータは ON のときだけ表示されます。

| パラメータ | 内容 |
|---|---|
| Split / merge（分裂・合体） | 領域ごとのタイミングで、その領域を分裂、または辺全体を共有する隣の領域と合体。写真タイルと CA の状態はそのまま、新しい領域のルール・向き・テンポを設定します。模様だけは変更した領域で初期化します |
| └ Interval（世代） | 12〜120、初期値80。1つの領域が組み替えを試す間隔の中心値。領域ごとに0.5〜1.5倍で揺らぐため、80なら40〜120世代。画面のあちこちで、ばらばらの時期に起きます。変更時は各領域の残り時間を新旧の設定値の比で伸縮します |
| Region leak（隣からの漏れ） | 「流れる」のときだけ表示・動作します。流れの入口から隣の領域のタイル・状態を取り込みます。写真の流し込み中は写真を優先し、画面外とはつなぎません |
| └ Amount | 0〜1、初期値0.6（60%）。0 で閉じる、1 で入口全体が開く。入口の幅を4等分した帯ごとに開閉を決め、24世代保ちます。OFF にしてもこの値を保持します |

両方とも再生中に変更できます。「分裂・合体」を OFF にすると、その時点の境界で固定します。「隣からの漏れ」を OFF にしても、すでに入ったタイルは残ります。初期状態から比較するには、設定を変更して **R** を押してください。

開発サーバでは [4画面の比較ページ](http://localhost:5173/experiments/regions.html) も使えます（`experiments/regions.html`。通常の公開ビルドには含めません）。同じ写真・seed・世代で「従来／分裂・合体／漏れ／両方」を並べます。**Space** で再生・停止、**R** でリセット、**B** で境界線、写真のドロップで4画面の素材をまとめて変更できます。比較用に写真の流し込み・模様は OFF、漏れは 60% にしています。

## 決定性

映像の中身は **seed・パラメータ・世代番号** だけで決まります。壁時計の時間やフレーム落ちには依存しません（処理が追いつかないときは、ゆっくりになるだけで、中身は変わりません）。

再生中に即時のパラメータを変えた場合も、「何世代目に何をいくつに変えたか」が同じなら同じ映像になります。この操作の記録・再生はまだ実装していません（PNG にはパラメータを埋め込んでいません。ファイル名に seed と世代番号が入ります）。

## ファイル構成

```
index.html              エントリ（キャンバスと情報表示）
src/
  main.js               画像の読み込み、GUI、キー操作、再生ループ
  image.js              グリッド配置、パディング、縮小（kivi から流用）
  engine/               エンジン本体。DOM に依存しない純粋な JS（Node でも動く）
    sim.js              Simulation：世代番号・状態・step()、再生中に変えられるパラメータ
    analyze.js          平均色 → k-means → 分類 → 代表タイル（kivi から流用）
    rules.js            ルール表（性格、chaos の即時反映）
    regions.js          領域の再帰分割（kivi から流用）
    scale.js            大きなマス（倍率ごとの分類・代表タイル、領域の倍率、中のマスへの書き写し）
    flat.js             塗りつぶすタイルの選び方（kivi の pickFlat を kuva 向けに）
samples/                サンプル画像（開いたときにランダムに1枚を表示）
    motions.js          領域の動き方（流れる／その場で変化／元写真のまま）、ルールの変形、写真の流し込み
    rng.js              乱数とハッシュ
  render/renderer.js    WebGL2 描画
test/                   Node のテスト（npm test）
```
